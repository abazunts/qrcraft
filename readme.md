Генератор QR-кодов


Пользователь делает сам → сервис генерирует QR-код

Что можно дать по подписке:
1. Неограниченное количество QR-кодов
   Бесплатно ограничено, подписка снимает лимит.
2. Разные типы QR-кодов
   • URL
   • Текст
   • Контакты (vCard)
   • Wi-Fi подключение
   • События в календаре
3. Настройка дизайна
   • Цвет
   • Логотип
   • Форма углов и точек
4. Статистика и редактирование
   • Сколько раз отсканировали QR
   • Возможность менять ссылку без смены QR
5. Экспорт и хранение
   • PNG, SVG, PDF
   • Сохранять в аккаунте для повторного использования
